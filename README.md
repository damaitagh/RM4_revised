# YOLO26n 训练对比与改进逻辑

## 1. 核心实验对比

前六组均为同一验证集上的结果，最终测试集成绩单独列出。表中成绩取训练结束时对 `best.pt` 的验证输出，保留三位小数。

| 实验 | 训练数据 | 输入尺寸 | Epoch | 主要调整 | mAP50 | mAP50–95 |
|---|---|---:|---:|---|---:|---:|
| 1：基线 | 原始训练集 1208 张 | 640 | 50 | 建立对照 | 0.938 | 0.625 |
| 2：扩充数据 | 1505 张 | 640 | 50 | 加入预标注并人工修正的 297 张图片 | 0.941 | 0.627 |
| 3：提高分辨率 | 1505 张 | 960 | 50 | 640 → 960 | 0.953 | 0.669 |
| 4：延长训练 | 1505 张 | 960 | 100 | 50 → 100 Epoch | 0.960 | 0.683 |

| 6：再次修正标签 | 1505 张 | 960 | 100 | 复查新增标签，其余配置保持一致 | 0.959 | **0.686** |

## 2. 改进逻辑与结果分析

### 2.1 建立基线，判断新增数据的价值

使用 YOLO26n，在原始训练集上以 640 分辨率训练 50 轮，得到 mAP50–95 为 0.625 的基线。

随后利用基线模型对未标注图片进行预标注，经人工修正和筛选后，将 297 张图片加入训练集。在训练参数不变的情况下，指标提高到 0.627，说明这次数据扩充的收益较小，增加数据量并不一定带来明显提升。

### 2.2 提高训练分辨率

考虑到数据中存在远距离、小尺寸机器人，将输入尺寸由 640 提高到 960，保留更多目标细节。mAP50–95 从 0.627 提高到 0.669，增加 **4.2 个百分点**，是各次调整中最大的提升。

同时进行了交叉验证：640 训练的模型仅将推理尺寸改为 960，mAP50–95 只从 0.6282 提高到 0.6307。因此，这次改善不能简单归结为预测时放大图片，训练阶段使用较高分辨率也很重要。

### 2.3 延长训练，检验进一步增大推理尺寸的效果

在 960 分辨率下，将训练轮数从 50 增加到 100，mAP50–95 从约 0.669 提高到 0.683，仍有收益，但增幅减小。

随后测试将该模型的推理尺寸提高到 1280，指标反而由 0.6839 降到 0.6728，推理耗时也增加，因此最终保留 960 输入尺寸。

### 2.4 根据训练曲线调整 Mosaic

观察到此前训练末段关闭 Mosaic 后验证指标下降，因此尝试全程保留 Mosaic，检验这一调整是否有效。

最终 mAP50–95 约为 0.684，与之前基本持平。这次实验没有获得明显提升，也说明不能仅凭训练曲线中的一次下降就确定原因。

### 2.5 检查标签质量

在查看预测结果时发现背景误检等问题，于是重新检查新增训练图片的标签。本次共有 167 份标签发生变化，新增数据的目标框总数由 1331 调整为 1307。

保持训练配置不变重新训练后，mAP50–95 小幅提高到 0.686，但召回率由 0.926 降到 0.911，说明各项指标并非同时改善，不能把这次修正描述成全面提升。

## 4. 实验结论

从基线到最终模型，验证集 mAP50–95 由 **0.625 提高到 0.686，累计增加约 6.1 个百分点**。

主要收益来自提高训练分辨率，其次是延长训练；扩充数据、保持 Mosaic 和再次修正标签的收益相对有限。

最终测试结果低于验证结果约 1.18 个百分点。
